# Integrations

Nimbus connects with tools your team already uses.

## Slack
Open **Settings → Integrations → Slack** and click **Connect**. Once linked, you can get
task notifications in a Slack channel and create tasks from Slack with the /nimbus command.

## Google Calendar
Connect under **Settings → Integrations → Google Calendar** to see task due dates on your
calendar. Syncing is one-way (Nimbus to Calendar) and updates every 15 minutes.

## API and webhooks
Business-plan customers can generate API keys under **Settings → Developer**. The API lets
you create and read tasks programmatically, and webhooks can notify your systems when
tasks change. See the developer docs for endpoints and rate limits.

## Zapier
A Nimbus Zapier app is available for connecting to thousands of other tools without code.
Search for "Nimbus" in Zapier and authenticate with your account.
