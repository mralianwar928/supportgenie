# Getting Started with Nimbus

Nimbus is a project management tool for small teams. This guide covers your first steps.

## Creating your first project
1. From the dashboard, click **New Project** in the top-right.
2. Give the project a name and (optionally) a description.
3. Choose a template (Kanban, List, or Timeline) or start blank.
4. Click **Create**. You'll be taken straight to the new project board.

## Adding tasks
Inside a project, click **Add Task**, enter a title, and press Enter. You can set a due
date, assignee, and priority by opening the task and editing its fields.

## Switching views
Every project can be viewed as a Board, a List, or a Timeline. Use the view switcher at
the top of the project to change how tasks are displayed. Your choice is saved per project.

## Mobile app
Nimbus is available for iOS and Android. Sign in with the same email and password you use
on the web. Changes sync automatically across all your devices.
